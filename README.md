# HK STORE

واجهة إدارة محل HK STORE بالعربية، مع تطبيق Windows وتطبيق Android.

## الوظائف الحالية
- المبيعات ومخزون البيع والزبائن والديون والتقارير والنسخ الاحتياطي محلياً على كل جهاز.
- حسابات مدير وبائع وتقني وزبون اللوح، مع إظهار الواجهات حسب الدور.
- تسجيل أجهزة الصيانة ومتابعة الحالات.
- مخزون مستقل لقطع غيار الصيانة.
- خدمة طلب تعبئة الرصيد بين جهاز Windows ولوح Android على شبكة Wi-Fi المحلية: يحدد البائع المتعامل والمبلغ، ويُدخل الزبون رقم الهاتف، ثم يراجع البائع الطلب ويؤكده.

## إعداد ربط لوح الزبون
1. ثبّت وشغّل تطبيق HK STORE على جهاز Windows واجعله متصلاً بشبكة Wi-Fi نفسها التي يتصل بها اللوح.
2. سجّل الدخول إلى Windows بحساب المدير أو البائع. سيبدأ خادم الشبكة المحلي على المنفذ 8787، وستظهر نافذة فيها عنوان جهاز البائع ورمز ربط اللوح.
3. على اللوح، افتح تطبيق HK STORE. في شاشة الدخول أدخل عنوان جهاز البائع ورمز اللوح ثم اضغط «حفظ الاتصال».
4. أنشئ حساب «زبون اللوح» على اللوح من حساب المدير (يمكن استخدام حساب المدير الأولي عند الإعداد فقط)، ثم ادخل بحساب الزبون. على جهاز البائع، حدد المتعامل والمبلغ؛ سيظهران على اللوح. يدخل الزبون رقم هاتفه ويرسله، ويظهر الطلب عند البائع خلال ثوانٍ.
5. اسمح لتطبيق HK STORE عبر جدار حماية Windows على الشبكة الخاصة عند ظهور الطلب. لا تفتح المنفذ 8787 على الإنترنت.

## بيانات الدخول الأولية
حساب المدير الأولي: اسم المستخدم `manager` والرمز `1234`. غيّر الرمز فور الإعداد وأنشئ حسابات العاملين. لا تترك الرمز الافتراضي.

## حدود مهمة قبل الاستخدام التجاري
- خدمة التعبئة الحالية تسجل الطلب وتؤكد استلامه داخلياً فقط؛ لا تنفذ شحناً فعلياً. يلزم عقد/حساب موزع معتمد أو API رسمي لكل متعامل لإجراء التعبئة.
- مزامنة Wi-Fi الحالية تخص طلبات التعبئة فقط. بيانات المبيعات والمخزون والزبائن والصيانة لا تزال محفوظة محلياً على كل جهاز وليست قاعدة بيانات مشتركة.
- كلمات مرور حسابات التطبيق الحالية محفوظة محلياً بصيغة غير مشفرة؛ لا تستخدم بيانات حساسة أو تشغيل مالي حقيقي قبل استكمال نظام مصادقة وتخزين آمنين واختبارات الأمان.
- رمز اللوح ورمز البائع مخصصان للشبكة المحلية. لا تشارك رمز البائع، ولا تستخدم شبكة Wi-Fi عامة.
- مواقيت الصلاة والتنبيهات لم تُربط بعد بمصدر مواقيت معتمد.

# HK STORE camera integration — Somfy VISIDOM ICM100

## Exact model

The shop camera specified for this project is **Somfy VISIDOM ICM100** (not the newer Somfy Indoor Camera generation).

Somfy's official ICM100 installation manual describes motion-triggered activation and push/email alerts through the Somfy VISIDOM app, Wi-Fi or Ethernet networking, and microSD recording. The manual lists TCP/IP, UDP, SMTP, NTP, DHCP and ARP, but does not document an RTSP stream, ONVIF service, or a camera-to-custom-webhook feature. Therefore HK STORE must not assume RTSP port 554 or claim that a successful TCP port probe proves video or motion-event integration.

Official manual: https://service.somfy.com/downloads/ac_v5/5121802a000-visidom-icm100-10lgs-web-.pdf

## What HK STORE implements

- Manager-only camera setup and welcome-message settings in the app.
- Local server event receiver: `POST /api/camera/event`.
- A random 256-bit camera event token is created by the Windows LAN server and shown only in the manager camera settings after local connection.
- Event polling: `GET /api/camera/events?after=<event-id>`, protected by the seller key and loopback restriction.
- Motion events can trigger a short Algerian Darija greeting generated by the local Ollama model. If the model is unavailable, the manager's saved phrases are used.
- A manager-only simulated motion button tests the receiver and speech path; it is explicitly a test, not proof that the Somfy camera sent an event.
- A 45-second greeting cooldown prevents repeated speech from a burst of motion events.
- No face recognition, identity inference, or recording of customer identity.

## Event payload for a bridge

A local bridge may send:

```http
POST /api/camera/event
Content-Type: application/json
X-HK-Camera-Token: <manager camera event token>

{"event":"motion","camera":"Somfy VISIDOM ICM100"}
```

For a bridge running on the Windows shop computer without TLS, use `http://127.0.0.1:8787/api/camera/event`. The default server is loopback-only. For a bridge on another device, configure a trusted TLS certificate; the server then listens on the LAN interface. Keep the token secret and never put it in a public page or screenshot.

## Remaining physical integration step

The ICM100 manual does not show a direct webhook output. To make automatic greetings real, a separate trusted bridge must receive the camera's Somfy VISIDOM motion notification (for example, via a supported email-notification workflow) and forward only a verified motion event to the HK STORE endpoint above. That bridge is not bundled or claimed as complete because the camera's notification mailbox/provider and a supported event extraction method have not yet been configured or tested.

The manual test button proves only that HK STORE can accept a correctly authenticated event and play a greeting on the Windows computer. Test actual camera motion separately after an event bridge is installed.
